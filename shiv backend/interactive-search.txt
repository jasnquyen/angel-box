Interactive Search
==================

Purpose:
- Handle user "from -> to" route input.
- Normalize shorthand locations (example: "klaus", "north ave").
- Run suggestion + route lookup flow.

Suggested pipeline:
1. Input validation and normalization.
2. Google Places autocomplete/details lookup.
3. Route API lookup (walking/driving).
4. Route optimization pass (optional).
5. Return map-ready response (path, ETA, distance, safety metadata).

Core fields:
- from
- to
- normalized_from
- normalized_to
- travel_mode
- route_polyline
- eta_minutes
- distance_miles
- emergency_call_boxes
- camera_density_score
